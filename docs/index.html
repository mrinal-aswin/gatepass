    What's in the file

    Everything you need to apply, in about twenty minutes.

    One run builds the whole pack. When your resume or LinkedIn changes, it updates only what's affected and keeps every fact you've already confirmed.

    1. 01

      A resume that clears the filters

      One page, built to survive the automatic screening most companies run before a person reads anything. PDF to upload, Word for portals that want it.

    2. 02

      A resume for each kind of role

      Applying to frontend and backend jobs? You get one for each role your experience genuinely supports. Same facts, different emphasis.

    3. 03

      Tailored to one job, in seconds

      Paste a job ad, get a version reordered for it, and an honest list of what it asks for that you can't claim. Each one is kept with its ad.

    4. 04

      LinkedIn fixes, ready to paste

      Headline, About and experience text with the steps to apply them. When you've made the changes, Claude re-reads your profile and checks each one.

    5. 05

      Five reviewers before the real ones

      A recruiter, hiring manager, technical interviewer, background checker and domain lead each judge your materials, separately.

    6. 06

      Live job research

      Current listings for your target roles and cities, and the keywords those ads keep asking for.

    7. 07

      Cover letters

      A main letter, a short version for emails and LinkedIn messages, and a tailored letter for any job on request.

    8. 08

      Interview preparation

      A six-week plan, a bank of stories to tell, and a ready-made prompt that turns ChatGPT into a mock interviewer.

    9. 09

      A dashboard to work from

      Every improvement as a card to tick off, your scores, your documents, and a weekly tracker that shows where applications get stuck.

    Just say it

    Plain words. No commands to learn.

    ~/job-search · claude
    “I have a new resume.”Stores it, shows what changed, and updates only what that affects.
    “My LinkedIn changed.”Re-reads your profile, checks each fix you made, and re-scores it.
    “Tailor my resume to this job.”Paste the ad. You get a tailored resume and an honest list of gaps.
    “Write a cover letter for this job.”A letter built from the same facts as the resume.
    “This week: 8 applications, 2 replies.”Logged to your funnel, which shows where you're losing applications.
    “My teammate wants to prepare for senior roles.”A separate pack for them, once they've agreed.
    Get started

    Ten minutes to set up. Your first pack about twenty more.

    You need Claude Code, which comes with a paid Claude plan (Pro, Max, Team or Enterprise) or an Anthropic Console account. The plugin itself is free.

    1. Install Claude Code and sign in

      Install it from claude.com/claude-code. Then open Terminal, type claude, press Enter, and finish signing in in the browser window that opens.

      Opening Terminal: on a Mac press Cmd + Space and type Terminal. On Windows, open PowerShell from the Start menu.

    2. Add the plugin

      Paste these into Terminal, one at a time, pressing Enter after each. Each ends with a green tick.

      claude plugin marketplace add mrinal-aswin/gatepass
      claude plugin install gatepass@gatepass

    3. Make a folder and open Claude there

      mkdir -p ~/job-search && cd ~/job-search && claude

      If it asks whether you trust this folder, choose Yes. You're ready when you see a box to type in. On Windows, use this in PowerShell instead:

      mkdir $HOME\job-search; cd $HOME\job-search; claude

    4. Let Claude check your computer

      Type this to Claude

      Check the gatepass setup and help me install anything that's missing.

      It looks for five things (Python, pandoc, poppler, a Chrome-family browser and SQLite) and helps you install what's missing. Claude asks before it runs anything; choose Yes to let it. You're set when it says Ready.

    5. Build your pack

      Type this to Claude

      Build my job-search pack.

      Then add your resume: drag the file into the window (in Terminal this pastes its location) and press Enter. Claude asks a few questions, one at a time: whose profile it is, your LinkedIn, the jobs and cities you want, and how to handle missing details. It's done when it says your pack is ready.

    6. Open your dashboard

      Type this to Claude

      Start my dashboard.

      Open the link it gives you, usually http://127.0.0.1:8765. Keep Terminal open while you use it; closing it stops the dashboard. Start with Do next.

    Your data stays yours

    Private by default.

    • Everything stays on your computer. Your packs are ordinary files in your own folder, and the dashboard runs only on your machine.
    • Consent first. Before building a pack for someone else, Claude checks that they know and agree.
    • No passwords. Claude reads LinkedIn through your own signed-in browser, or from a PDF you export. It never asks for your password.
    • Nothing personal in the plugin. Its own checks fail if a real name, email or document is ever added to it.
    Questions

    Good to know.

    How much does it cost?

    The plugin is free and MIT-licensed. It uses your normal Claude Code allowance; a first pack is the biggest job, and updates use much less.

    How does Claude read my LinkedIn?

    Either through the Claude in Chrome extension, using your own sign-in, or from the PDF you get with More, then Save to PDF on your profile.

    Which computers does it work on?

    Tested on macOS. Linux should work. Windows is untested so far.

    Claude says it can't read my file.

    Macs protect the Downloads, Desktop and Documents folders. Claude gives you a one-line command to copy the file somewhere it can read. Paste it into Terminal and tell Claude it's done.

    How do I update or remove it?

    Run claude plugin update gatepass@gatepass to update, or claude plugin uninstall gatepass@gatepass to remove it. Your packs are never touched.

    I installed it when it was called resume-pipeline.

    Version 2.0 renamed it, so switch once: claude plugin uninstall resume-pipeline@resume-pipeline, claude plugin marketplace remove resume-pipeline, then the two install commands under Get started. Your packs carry over unchanged.

    Can I share the dashboard with a teammate?

    Yes. It's a single file with everything inside, including the documents, so you can send it to the person whose pack it is.
