What this page is

The whole job search on one page, organised as a hiring funnel. Each gate, from G1 (found in search) to G8 (background check), is a point where an application can be lost, and each has its own evaluator. Every finding links to the action that fixes it.

How to work through it

  1. Overview: start with Do next. It follows the framework's order: background-check risk first (it can cost an offer), then the earliest Red gate.
  2. Actions: each action is one line; select it to open. A red edge marks P0, amber P1. Each card has why, a link to the exact page, text to copy (with LinkedIn's length limits) and step-by-step instructions. Mark it Resolved or Ignored when done.
  3. Lenses: what each independent reviewer (recruiter, hiring manager, technical interviewer, HR, domain lead) concluded, and the findings two or more of them agreed on.
  4. ATS: keyword coverage on the resume and on LinkedIn. Skills the resume proves but LinkedIn lacks can be copied and added in one go.
  5. Funnel: once applications start, log each week's numbers. The page shows conversion at each step and names the gate that's leaking.

Saving changes

Best: run the local server. From the workspace folder run actions.py serve and open the address it prints. Every click and funnel week is then saved to tracker.sqlite and applied to the source files immediately, with a log under Overview, Recent changes. The server listens on this computer only.

Opened as a file instead? Clicks are remembered in this browser only. When the bar appears at the bottom, Copy update command gives a terminal command that records and applies the change, or use Copy message for Claude. Changes kept in the browser can be sent later with Save to database once the server is running.
